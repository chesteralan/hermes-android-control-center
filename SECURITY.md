# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Use [GitHub's private vulnerability reporting for this repository](https://github.com/chesteralan/hermes-android-control-center/security/advisories/new) when available. If private reporting is unavailable, contact a repository maintainer privately through GitHub.

Include the affected version or commit, platform, impact, and concise reproduction steps. Redact device serials, IP addresses, credentials, pairing codes, session contents, and other personal or secret data. Do not attach private keys or unredacted diagnostics.

There is currently no published response-time SLA. Maintainers will assess reports and coordinate disclosure with the reporter.

## Supported versions

Security fixes are prioritized for the latest development version. Release support windows will be published when stable releases are available.
